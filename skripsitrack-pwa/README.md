# SkripsiTrack PWA
Pencatat progres bimbingan skripsi (PWA, HTML/CSS/JS + REST API).

## Menjalankan lokal
1. Edit `config.js` -> isi `API_BASE` dengan URL API Modul 1.
2. (Tes tanpa API) `npx json-server db.json --port 3000`
3. `npx serve .` lalu buka alamat yang tampil.

## Deploy
Netlify / Vercel / GitHub Pages (tanpa build).
